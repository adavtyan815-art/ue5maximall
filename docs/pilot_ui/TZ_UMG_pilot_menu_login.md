## 1. Правила перевода макета (1440) в UMG (1920×1080)

1. **DPI.** Используется кривая Shortest Side по умолчанию, точка 1080 → 1.0 (`BaseEngine.ini:1393`, в `Config/DefaultEngine.ini` не переопределена). Виджеты верстаются под 1920×1080.
2. **Геометрия** (размеры, отступы, промежутки, радиусы, позиции): значение макета × 1.333 (README, строка 51). Дробные значения допустимы.
3. **Размер шрифта: не умножать.** В UMG `Size` = число px из макета. Slate рендерит шрифты при 96 DPI (`SlateFontInfo.h:15`, `RenderDPI = 96`), поэтому `Size N` даёт N × 1.333 px — нужный множитель уже встроен. Пример: 13.5 px в макете → `Size 13.5` → 18 px на 1080p.
4. **Межбуквенный интервал:** `LetterSpacing = em × 1000 × 1.333`, потому что Slate считает интервал от размера в пунктах (`SlateTextShaper.cpp:412`). Итог: 0.08em → **107**, −0.01em → **−13**, −0.015em → **−20**. Slate округляет интервал до целых px.
5. **Обводка.** CSS 0.5 px на retina равна 1 физическому px, в README указан 1 px → в UMG **1 px, не масштабировать**. То же для разделителей.
6. **Цвета** вводить в поле **Hex sRGB** пипетки. Linear-значения в таблице ниже — только для проверки.
7. **Размытие.** CSS `blur(40px)` → `BackgroundBlur` **Blur Strength 14–18** (README). Предлагаю 16, подобрать на глаз в редакторе.
8. **Теней нет** (README).

### Шрифт — блокирующий вопрос

В **Instrument Sans нет кириллицы**: Google Fonts отдаёт только подмножества `latin` и `latin-ext`. Русский текст в эталонных PNG нарисован системным шрифтом Mac из fallback-цепочки `-apple-system`, а не Instrument Sans. В проекте Instrument Sans тоже нет: в `Content` есть только `LiberationSans`.

Нужен Composite Font `F_InstrumentSans`:
- Default Typeface: Instrument Sans Regular (400), Medium (500), SemiBold (600), лицензия OFL;
- Sub-Font для диапазона U+0400–U+04FF (кириллица): **шрифт выбирает заказчик или дизайнер**. San Francisco из эталона вне Apple-платформ лицензировать нельзя. Ближайший открытый аналог — Inter (OFL): в макете его можно включить переключателем «Кириллица → Inter».

## 3. Общий рецепт стеклянной панели

```
BackgroundBlur        Blur Strength 16 · Corner Radius (R,R,R,R) · Apply Alpha To Blur ✓ · Padding 0
└─ Border             Brush: Draw As = Rounded Box, Tint = Glass (см. токены)
                      Outline: Color #FFFFFF α0.14, Width 1, Corner Radii (R,R,R,R), Rounding = Fixed Radius
                      Padding = внутренний отступ панели
   └─ содержимое
```

Радиус R у `BackgroundBlur.CornerRadius` и у `Border` должен совпадать. `Low Quality Fallback Brush` — None: заливку уже даёт Border.

**Кнопка на стекле** (≡, основная и второстепенная кнопки): у `Button` задать Style → Normal / Hovered / Pressed как Rounded Box с нужной заливкой и обводкой. Pressed = Hovered: в пакете нажатое состояние не задано. Кнопке ≡ нужен свой `BackgroundBlur` под ней.

**Цвет текста при наведении** (ссылки): у Button нет стиля для текста потомка. Менять `ColorAndOpacity` у TextBlock в `OnHovered` и `OnUnhovered`.

### Принцип

Существующие виджеты сохранили имена. Поэтому 46 привязанных событий кнопок, ссылки графа на поля ввода и 12 анимаций состояний входа работают без изменений. Граф BP не менялся.

- Меню: кнопки перенесены из холста в вертикальный список внутри `MyMainRoom`. Белая подложка `Image_59` и иконки пунктов свёрнуты.
- Вход: блоки состояний (`Login`, `SignUp`, …) остались на своих местах и сохранили слоты, на которые ссылаются анимации. Их содержимое перенесено внутрь карточки `SizeBox > BackgroundBlur > Border > VerticalBox`. Пустые старые контейнеры свёрнуты.
- Новые служебные виджеты называются `Maxi_*` и не являются переменными BP.
